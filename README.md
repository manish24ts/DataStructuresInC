# 📖 Overview

This repository contains implementations of fundamental **Data Structures** and **Algorithms** developed as part of academic coursework and programming practice.

The project covers linear and non-linear data structures, searching and sorting algorithms, graph traversal techniques, tree data structures, and stack/queue applications. Each program focuses on understanding the internal working of data structures through hands-on implementation.

---

# 🎯 Objectives

- Learn the fundamentals of data structures.
- Understand memory organization and dynamic allocation.
- Implement linear and non-linear data structures.
- Study searching and sorting techniques.
- Explore graph traversal algorithms.
- Practice tree operations and balancing.
- Develop efficient problem-solving skills.

# ⚙️ How to Run

Clone the repository

```bash
git clone https://github.com/manish24ts/DataStructuresInC.git
```

Move into the project

```bash
cd DataStructuresInC
```

Compile

```bash
g++ filename.cpp -o output
```

Run

```bash
./output
```

### Windows (MinGW)

```bash
g++ filename.cpp -o output.exe
output.exe
```
